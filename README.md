# InfoSec Challenge — Information Security Quiz

A simple browser-based quiz game for revising Information Security Management concepts.

## Run locally
Open `index.html` in a web browser. No installation or external libraries are required.

## Publish publicly with GitHub Pages
1. Create a **public** repository on GitHub, for example `infosec-quiz-game`.
2. Upload `index.html` to the top level of the repository (the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. Your site URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/infosec-quiz-game/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username. The URL cannot be finalized until you create the repository under your account.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
